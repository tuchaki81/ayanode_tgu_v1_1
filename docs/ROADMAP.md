# Roadmap experimental

Nenhuma etapa abaixo é considerada demonstrada até que seus critérios de teste sejam satisfeitos.

- [x] Separar núcleo testável da interface.
- [x] Calcular gradiente de spin com dependência da referência coletiva.
- [x] Validar numericamente derivadas e regras de normalização.
- [x] Exportar séries temporais para CSV.
- [x] Estruturar repositório para GitHub com testes automáticos.
- [ ] Confirmar troca real de estados entre dois navegadores via GUN com evidências reproduzíveis.
- [ ] Criar testes de integração para relay, reconexão, TTL e divergência de estados.
- [ ] Definir protocolo versionado, controle de tamanho e auditoria de mensagens.
- [ ] Adicionar segurança de rede apropriada antes de qualquer exposição pública.
- [ ] Medir tempos, escalabilidade e convergência com diferentes N e latência.
- [ ] Comparar com baselines clássicos de consenso/alinhamento.
- [ ] Testar ganho funcional em tarefas coletivas, além de alinhamento numérico.
- [ ] Discutir significado físico apenas após confrontação com dados externos.
