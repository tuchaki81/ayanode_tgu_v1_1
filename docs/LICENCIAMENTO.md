# Decisão de licenciamento — antes de anunciar uso livre

A publicação de código no GitHub não concede automaticamente permissão para que outras pessoas o reutilizem. Para evitar escolher uma licença irreversível em nome do titular, este pacote inclui `LICENSE` com reserva de direitos.

O titular pode optar por:

- **MIT:** permissiva, curta e permite uso comercial, modificação e redistribuição, exigindo conservar os avisos de copyright e licença.
- **Apache-2.0:** também permissiva, com concessão expressa de licença de patentes e requisitos próprios de avisos.
- **Manter reserva de direitos:** permite leitura pública, mas não oferece autorização geral de uso ou modificação.

Se escolher uma licença aberta, substitua **integralmente** o arquivo `LICENSE` pelo texto oficial correspondente, altere o README e confirme que possui direitos para licenciar os arquivos. Dependências de terceiros, como GUN, possuem licenças próprias.

A escolha deve ser feita pelo autor antes de divulgar o código como “software livre” ou “open source”.
